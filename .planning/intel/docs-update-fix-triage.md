## Verdict legend

- `path-rewrite` — mechanical path string substitution (one find-pattern → one replace-pattern, no prose restructuring); used when the referenced artifact moved on disk
- `adr-supersession-append` — append-only `## Update — YYYY-MM-DD` section appended to an ADR, NEVER an in-place edit above existing content; preserves ADR immutability per CF-05 + Pitfall 12 Integration Gotchas
- `change-id-anchor` — replace dangling archived-planning reference with stable closure change_id citation; reference itself is NOT deleted (forensic trail per Pitfall 12)
- `qualifier-add` — add a path or context qualifier to a bare identifier (e.g., bare `USER-PROFILE.md` → `$HOME/.claude/USER-PROFILE.md`); preserves surrounding sentence structure
- `filename-strip` — remove a specific filename from a parenthetical/bullet that references a file which was never shipped; surrounding prose remains intact
- `rename-file` — rename a translated file to match the en-source convention; uses `git mv`/`jj` equivalent to preserve history
- `link-rewrite` — update a markdown link target to the new canonical location (typically following a rename or to break a circular reference)
- `prose-correction` — surgical prose edit removing or correcting a factual claim about repo state (e.g., removing an inaccurate "this is a hook" claim); preserves surrounding context
