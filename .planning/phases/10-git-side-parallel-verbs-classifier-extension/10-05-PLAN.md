<objective>
Close SC2 and SC3 verification gaps in Phase 10 by patching
`sdk/src/vcs/git/parallel.ts`:

(1) **SC2 gap (CR-01):** STEP 1 of `performGitParallelFanIn` (line 323 loop)
currently iterates `handle.workspaces` UNCONDITIONALLY without consulting
`results[].exitCode`. A crashed agent that committed N partial commits before
crashing has its branch tip != baseRev, so the `merge-base --is-ancestor` probe
at line 335 does NOT skip it, and the `git merge --no-ff` at line 347 silently
merges the partial work into main. The orchestrator receives `conflicted: false`
and never learns the crash happened. Fix: filter `results[].exitCode !== 0`
agents OUT of STEP 1 before the probe, routing them EXCLUSIVELY through STEP 2's
crashed-agent classifier so the crashed-with-uncommitted-work queue entry is
the only side effect.

(2) **SC3 gap (CR-02):** STEP 3 audit at lines 461-469 enumerates EVERY
`worktree-agent-*` branch in the repo via `git for-each-ref refs/heads/worktree-agent-*`.
This conflates handles — in-flight conflict branches AND pre-existing
unrelated `worktree-agent-*` branches in the repo are misreported as surplus.
Fix: scope the sweep to
`expectedNames = new Set(handle.workspaces.map(ws => \`worktree-agent-${ws.agentId}\`))`;
alive branches NOT in this set are skipped.

Both fixes ship together in ONE plan because they share the same test fixture
wiring (mkdtemp setup, gitAvailable probe, createGitAdapter, W-2 lifecycle) and
both regression tests extend `sdk/src/vcs/__tests__/cmd-parallel-git.test.ts`.
Lint fix (SC5) is in a separate plan (10-06) because it targets a different
defect class (lint regex shape) and is independent.

Purpose: Without these fixes, the cross-backend `FanInResult` contract is
behaviorally broken on git — the boolean `conflicted` field does NOT distinguish
crash from in-tree-conflict (SC2), and the array `surplusBookmarks` field
includes branches that did not outlive THIS fan-in's cleanup (SC3). Phase 10's
"structural goal achievement" holds; the "behavioral goal achievement" (what
the SC text says it means) does not.

Output: Patched `sdk/src/vcs/git/parallel.ts` (~480 LOC unchanged size; surgical
edits only at lines 323 and 461) + two NEW `it` blocks in
`sdk/src/vcs/__tests__/cmd-parallel-git.test.ts` proving the fixes.
</objective>
