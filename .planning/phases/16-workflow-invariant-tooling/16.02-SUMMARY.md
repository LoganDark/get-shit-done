## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking issue] Generator script invocation required `pnpm exec tsx` not direct `node`**

- **Found during:** Task 1 (CLI bridge registration)
- **Issue:** Plan said "if a regenerator exists, run it; otherwise hand-edit." The regenerator at `sdk/scripts/gen-command-aliases.ts` is a TypeScript file with relative imports of `../src/query/...js` files (source paths, not dist). Running with `node --experimental-strip-types` fails because Node ESM resolution would need pre-compiled `.js` files at the source paths. Plain `tsx` was needed.
- **Fix:** Invoked via `pnpm exec tsx scripts/gen-command-aliases.ts` from inside `sdk/`. The regenerator updated both the TS file at `sdk/src/query/command-aliases.generated.ts` AND its CJS mirror at `get-shit-done/bin/lib/command-aliases.generated.cjs` in one pass.
- **Files modified:** None (the regenerator output is the same content I would have hand-edited; just used the tool).
- **Commit:** `tvusomourlqz`

**2. [Rule 3 - Blocking issue] Integration test PATH-shim must live OUTSIDE the colocated jj working tree**

- **Found during:** Task 3 (dogfood-restore.sh integration test)
- **Issue:** Initial test placed the PATH-shim inside `fixDir` (the synthetic jj repo). The dogfood-restore.sh script invokes `jj op restore $PRE_OP_ID` which snapshots the working copy first then restores to the captured op-id. Files added AFTER the captured op-id (like the test's PATH-shim) get rolled back by the restore. The script then could not find the shim on PATH and fell through to the user's globally-installed `gsd-sdk` (which lacks the bridge until the next `pnpm install` of this fork).
- **Fix:** Moved the shim to a separate `mkdtempSync(path.join(tmpdir(), '__dogfood-test-shim-'))` directory OUTSIDE `fixDir`. The finally block now cleans up `fixDir`, `tarBundle.tarDir`, AND `shimDir`.
- **Files modified:** `tests/scripts/dogfood-restore-orphan-cleanup.test.cjs` (single test file, all in Task 3 commit).
- **Commit:** `tvxtzmovmuyz`
- **Pattern note:** This is a non-obvious gotcha that future tests invoking `dogfood-restore.sh` (or any bash script using `jj op restore`) need to be aware of. Captured in patterns-established frontmatter.
