## Disposition vocabulary

Every ledger row's disposition MUST start with exactly one of these six prefixes (the 19-13 completeness proof parses them):

- `ported-to:<path>` — fork content re-homed at a new path in the upstream layout
- `re-applied-at:<path>` — fork semantic delta re-applied onto the upstream counterpart file
- `dropped:<reason>` — content deliberately removed from the resolved tree
- `adopted-upstream` — upstream's version/tree taken as-is
- `substrate:<reason>` — raw-git (or similar) retained as backend-internal substrate with justification
- `merged` — genuine two-sided merge of both sides' content
